## 📚 附录：术语大白话对照表

| 术语 | 大白话解释 |
|------|------------|
| 融合概率 | 多个模型综合算出的结果发生概率，数值越高越容易中 |
| EV（期望收益） | 长期反复买这个选项，平均每100块能赚多少钱；正数=长期赚，负数=长期亏 |
| SP赔率 | 中了之后的赔付倍数，比如SP=4.0就是投100中了拿400 |
| 让球盘 | 主队让1球之后再算胜平负，用来平衡强弱差距 |
| 平系策略 | 专门挑上半场容易打平的比赛，双选「平平+平X」，胜率更稳 |
| 二串一 | 两场比赛都中才算赢，赔率是两场相乘，收益更高、难度更大 |
| 稳胆 | 概率极高的选项，串关里用来打底，降低整体风险 |
| 市场过热 | 热门方向买的人太多，赔率被压低，长期买性价比低 |
